# World 1 Levels 4–10 & Planned Traps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the planned traps (`bananaPeel`, `rubberChicken`, `chompCoin`, `fakeDoor`, ceiling spikes, multi-stop `runningDoor`) and World 1 Levels 4–10 with Hinglish copy, 3D visuals, Web Audio SFX, and bot-verified fairness tests.

**Architecture:** Extend the pure-logic fixed-60Hz simulation (`src/core/level.js`, `src/core/game.js`) with new ASCII trap tiles and deterministic trap states, keeping zero per-frame allocations in `step()`. Wire 3D models (`banana_peel.glb`, `rubber_chicken.glb`) and procedural meshes (`chompCoin`, ceiling spikes, `fakeDoor` collapse) in `src/render/world.js`, `src/render/momo.js`, `src/audio.js`, and `src/main.js`, then author Levels 4–10 in `src/levels.js` + `src/i18n.js` backed by bot death/win tests in `src/core/solutions.test.js`.

**Tech Stack:** JavaScript (ES modules), Three.js (`^0.170.0`), Vite (`^6.0.7`), Vitest (`^2.1.8`), Web Audio API.

**Spec:** [GAME_DESIGN.md](../../../docs/GAME_DESIGN.md) (Sections 3, 4.2, 5.5–5.9, 6.1–6.4, 9, 11–13)

## Global Constraints

- Deterministic fixed `1 / 60` s physics; zero RNG deaths (same input = same result).
- `step()` in `src/core/game.js` reuses `g.events` without per-frame array allocations; no DOM or Three.js imports inside `src/core/`.
- Precision windows `>= 0.12` s; gap widths `< 4.6` tiles; jump height `~2.59` tiles (`PHYS.jump = 14.4`, `PHYS.gravity = 40`).
- Every level must kill a naive player via its trap AND be beatable with 0 deaths (enforced by `src/core/solutions.test.js`).
- All player-facing text lives in `src/i18n.js` (Hinglish `hi` table); no hardcoded UI strings in `src/levels.js` or `src/main.js`.
- Only crimson/red (`#8b0d1a`, `#c4213a`) is used for hazards; non-trap art stays candy-pastel; `prefers-reduced-motion` stays respected.

## Review Focus

- Multi-stop `runningDoor` skipping two stops in one frame or failing to reset `stopIndex` on death -> pinned to Task 1 (`game.test.js` multi-stop + respawn test).
- `bananaPeel` slip persisting across death/respawn or breaking wall collisions -> pinned to Task 2 (`game.test.js` slip duration, blocked jump, wall & respawn reset tests).
- `rubberChicken` double-triggering mid-ascent and causing infinite height -> pinned to Task 3 (`game.test.js` 2x bounce + ceiling spike + non-retrigger test).
- `fakeDoor` (`X`) triggering real `win` instead of `fakeWin`, or leaving collapsed `fallingFloor` tiles missing after respawn -> pinned to Task 4 (`game.test.js` fakeWin + floor collapse + respawn test).
- World 1 Levels 4–10 having unreachable jumps (`>= 4.6` tiles), tight windows (`< 0.12` s), or non-lethal naive paths -> pinned to Task 5 (`solutions.test.js` naive death + 0-death win + precision window tests for L4–L10).
